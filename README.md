# BUMBLE-WEBDEMO
Bumble Landing Page Clone is a modern front-end web application inspired by the official Bumble website. It showcases a stylish and visually engaging landing page with clean layouts, attractive sections, and responsive design principles using pure HTML and CSS.

# 🧰 Tech Stack
- HTML5 – Structure of the web page
- CSS3 – Styling and layout
- bumble.css
- Remix Icons – Icon library
- Font Awesome – Additional icons


# ✨ Features
- Modern Bumble-inspired UI design
- Attractive hero section with layered visuals
- Fixed navigation bar
- Multiple stylish landing sections
- Clean and structured layout
- Reusable buttons and UI elements
- Responsive-friendly structure
- Organized assets folder

# 🚀 Getting Started

To run this project locally:

Clone this repository or download the ZIP
Open bumble.html in your browser
